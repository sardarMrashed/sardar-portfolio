# Sardar Rashid — Full-Stack Developer Portfolio

A responsive portfolio website for **Sardar Mohammed Rashid**, a JavaScript full-stack developer based in the Kurdistan Region, Iraq.

**Live website:** [sardar-portfolio.vercel.app](https://sardar-portfolio.vercel.app/)

## What's included

- Clear recruiter-facing overview and one-click email contact
- Four real projects with GitHub source links and applicable demos
- Full-stack capabilities, freelance experience and educational background
- Mobile navigation and responsive layouts
- Keyboard focus states, skip link and reduced-motion support
- Search engine and social preview metadata

The portfolio's project illustrations are **concept illustrations**, not screenshots of the actual applications. Project names, code and demos are linked to their respective repositories.

## Tech stack

- React 19
- JavaScript
- CSS (no additional styling framework)
- Create React App build tooling

## Run locally

Requires Node.js and npm.

```bash
npm install
npm start
```

## Check the build and tests

```bash
npm test -- --watchAll=false
npm run build
```
